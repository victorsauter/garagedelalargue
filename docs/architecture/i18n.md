# i18n

- Library: **next-intl** v4
- Locales: `fr`, `de`, `en` — default `fr`, prefix **always**
- Config: `i18n/routing.ts`, `i18n/request.ts`, `i18n/navigation.ts`, `middleware.ts`
- Messages: `messages/fr.json`, `de.json`, `en.json`

## What is translated

| Content | Strategy |
| --- | --- |
| Chrome (nav, sticky bar, buttons, form labels) | next-intl |
| Vehicle description | FR source in `Vehicle.descriptionFr`; DE/EN in `VehicleTranslation` |
| Legal pages | French only (same body on /de and /en) |
| Hours / address / phone | Facts in `lib/garage.ts`; labels translated |

Admin **Translate** calls DeepL (`lib/deepl.ts`). Free keys ending in `:fx` use `api-free.deepl.com`. If `DEEPL_API_KEY` is missing, the UI says so and DE/EN fields stay manual.

Fiche display: `descriptionForLocale` uses translation if present, otherwise French.
